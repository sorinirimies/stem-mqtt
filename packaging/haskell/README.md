# Haskell bindings

Generated by [`uniffi-bindgen-haskell`](https://github.com/mercury/uniffi-bindgen-haskell), pinned
by `--rev` in `scripts/bindings/spec.nu`. Earlier revisions needed a local patch (constructor
arguments, flat-error messages, `DuplicateRecordFields`); upstream fixed all three, so the
generator is installed unpatched and this directory holds only `cabal-header.txt` and `hackage/`.

## Callbacks

Callback interfaces are exposed only as opaque handles, so a Haskell program cannot implement
`MqttMessageListener` & co. Use the pull-style API: `mqttClientEnableMessageQueue` /
`mqttClientNextMessage` and `mqttBrokerEnableEventQueue` / `mqttBrokerNextEvent`.
