# stem-mqtt-go

MQTT 3.1.1 / 5.0 client **and broker** for Go (cgo), with a Rust core, via generated
[UniFFI](https://mozilla.github.io/uniffi-rs/) bindings.

```go
import (
    "github.com/sorinirimies/stem-mqtt-go/mqtt_broker"
    "github.com/sorinirimies/stem-mqtt-go/mqtt_client"
)
```

## Native libraries

The module links the Rust libraries `libmqtt_client` and `libmqtt_broker`, which you install
separately — download them from the
[release assets](https://github.com/sorinirimies/stem-mqtt/releases) or build them with
`cargo build --release -p stem-mqtt-client -p stem-mqtt-broker` — and point cgo at them:

```sh
export CGO_LDFLAGS="-L/path/to/libs"
export LD_LIBRARY_PATH=/path/to/libs   # DYLD_LIBRARY_PATH on macOS, PATH on Windows
go build ./...
```
