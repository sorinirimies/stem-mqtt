# Node.js / TypeScript

ESM bindings generated by [`uniffi-bindgen-node-js`](https://github.com/criccomini/uniffi-bindgen-node-js),
loading the Rust library through [koffi](https://koffi.dev/). One npm package with two entry points.
Read the [shared concepts](README.md) first for the option records and semantics.

## Install

```sh
npm install @sorinirimies/stem-mqtt-node
```

```js
import * as mqtt from "@sorinirimies/stem-mqtt-node/client";
import * as brk from "@sorinirimies/stem-mqtt-node/broker";
```

(This replaces the hand-written napi-rs addon `stem-mqtt-client`, which had no broker.)

## Requirements

- Node.js 16+ (ESM — use `"type": "module"` or `.mjs`). **Server-side only**; there is no browser build
  (browsers can talk to the broker's WebSocket port with any MQTT.js client instead).
- The package bundles the native library for the platforms the release built (Linux x86_64 today).
  Other platforms need the library built from source and placed next to the generated code.
- No compiler is needed at install time: `koffi` ships prebuilt binaries.

## Quick start

```js
import * as mqtt from "@sorinirimies/stem-mqtt-node/client";
import * as brk from "@sorinirimies/stem-mqtt-node/broker";

const broker = new brk.MqttBroker({
  bind_address: "127.0.0.1", port: 0, ws_port: undefined, allow_anonymous: true, max_clients: 0,
  max_qos: brk.QoS.ExactlyOnce, max_retained_messages: 100, max_queued_per_client: 100,
  redelivery_interval_secs: 0, tls: undefined, max_packet_size: 0, max_outbound_queue: 0,
  session_expiry_secs: 0,
});
await broker.start();
const port = broker.bound_port();

const options = (client_id) => ({
  host: "127.0.0.1", port, client_id, version: mqtt.MqttVersion.V5, clean_start: true,
  keep_alive_secs: 30, username: undefined, password: undefined, will: undefined,
  connect_timeout_secs: 10, operation_timeout_secs: 5, auto_reconnect: false,
  reconnect_backoff_secs: 0, reconnect_max_backoff_secs: 0, tls: undefined,
  max_packet_size: 0, auth_method: undefined, auth_data: undefined,
});

let resolveMessage;
const got = new Promise((resolve) => (resolveMessage = resolve));
const sub = new mqtt.MqttClient(options("node-sub"));
sub.set_message_listener({ on_message: resolveMessage, on_disconnected: () => {} });
await sub.connect();
await sub.subscribe("demo/#", mqtt.QoS.AtLeastOnce);

const pub = new mqtt.MqttClient(options("node-pub"));
await pub.connect();
await pub.publish("demo/hello", new TextEncoder().encode("hello"), mqtt.QoS.AtLeastOnce, false);

const message = await got;
console.log(message.topic, new TextDecoder().decode(message.payload));

await pub.disconnect(); await sub.disconnect(); await broker.stop();
process.exit(0);   // see "Language notes"
```

## Client

- Methods return `Promise`s: `connect()`, `subscribe(filter, qos)`, `unsubscribe(filter)`,
  `publish(topic, payload: Uint8Array, qos, retain)`, `disconnect()`. `is_connected()`,
  `set_message_listener()`, `enable_message_queue()`, `last_disconnect_reason()` are synchronous.
- Property and method names keep the Rust snake_case (`client_id`, `keep_alive_secs`, `set_message_listener`).
- Enums are PascalCase members: `mqtt.QoS.AtMostOnce | AtLeastOnce | ExactlyOnce`,
  `mqtt.MqttVersion.V311 | V5`. Optional values are `undefined`.
- **Callbacks are plain objects** with the interface's methods — no class needed:
  `{ on_message: (m) => …, on_disconnected: (reason) => … }`. `message.payload` is a `Uint8Array`.
- **Or pull**: `client.enable_message_queue(16)`, then `await client.next_message(5000)` → a message, or nothing if the timeout passes.

## Broker

`new brk.MqttBroker(config)`; `await start()`, `await stop()`, `is_running()`, `bound_port()`,
`bound_ws_port()`, `bound_tls_port()`, `client_count()`. Every config field is required (the generator
has no default arguments): pass `0` / `undefined` for the ones you don't need.

```js
broker.set_event_listener({
  on_client_connected: (id) => console.log("+", id),
  on_client_disconnected: (id, reason) => console.log("-", id, reason),
  on_message_published: (id, topic, qos) => console.log(id, "->", topic),
});
// or: broker.enable_event_queue(64); const event = await broker.next_event(1000);
```

## Authentication

```js
broker.set_auth_provider({
  authenticate: (clientId, username, password) => username === "demo" && password !== undefined,
});
```

A refused client makes `await client.connect()` reject. Enhanced authentication (as in the test):

```js
broker.set_enhanced_auth_provider({
  step: (_id, _method, data, round) =>
    round === 0
      ? { outcome: brk.EnhancedAuthOutcome.Continue, data: new Uint8Array([7]) }
      : data && data[0] === 8
        ? { outcome: brk.EnhancedAuthOutcome.Success, data: new TextEncoder().encode("welcome") }
        : { outcome: brk.EnhancedAuthOutcome.Failure, data: new Uint8Array() },
});

const client = new mqtt.MqttClient({ ...options("node-eauth"), auth_method: "X-ADD-ONE",
                                     auth_data: new TextEncoder().encode("hello") });
client.set_auth_handler({ respond: (_method, challenge) => challenge.map((b) => b + 1) });
await client.connect();
```

## TLS

```js
import { readFileSync } from "node:fs";
const tls = { ca_cert_pem: readFileSync("ca.pem"), client_cert_pem: undefined,
              client_key_pem: undefined, insecure_skip_certificate_verification: false };
// client: { ...options("c"), tls }

const brokerTls = { port: 8883, cert_pem: readFileSync("server.pem"),
                    key_pem: readFileSync("server.key"), client_ca_pem: undefined };
// broker config: tls: brokerTls
```

## Language notes

- **Errors** are classes named `MqttError<Variant>` (`mqtt.MqttErrorProtocol`, …) — test with `instanceof`.
  Publishing to a wildcard topic rejects with `MqttErrorProtocol`.
- **The process may not exit on its own** while the native library holds handles; call `process.exit()`
  when you are done (the smoke test does).
- Packet payloads are `Uint8Array`, not `Buffer`; `Buffer.from(u8)` converts.

## Building from source

```sh
cargo build --release -p stem-mqtt-client -p stem-mqtt-broker
nu scripts/install_bindgens.nu node
nu scripts/publish_packages.nu stage node      # dist/node/{client,broker}/ + native libs
cd dist/node && npm pack
```

The end-to-end test is [`tests/bindings/node/smoke.mjs`](../../tests/bindings/node/smoke.mjs)
(`nu scripts/test_bindings.nu node`).

## Troubleshooting

- **`Cannot find module './client/index.js'`** — import the package entry points
  (`…/stem-mqtt-node/client`), not a path.
- **`Error: Failed to load shared library`** — no native library for your OS/arch in the package;
  build from source and copy `libmqtt_client.*` / `libmqtt_broker.*` next to `client/` and `broker/`.
- **`SyntaxError: Cannot use import statement`** — the file isn't ESM; use `.mjs` or `"type": "module"`.
- **Hangs at the end** — see "The process may not exit".
