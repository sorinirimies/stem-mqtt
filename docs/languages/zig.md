# Zig

Zig bindings generated by [`uniffi-bindgen-zig`](https://github.com/sorinirimies/uniffi-bindgen-zig): one
file per component (`mqtt_client.zig`, `mqtt_broker.zig`) plus the shared `uniffi.zig`, imported by your
program and linked to the native libraries. Read the [shared concepts](README.md) first for the option
records and semantics.

## Install

From the [release](https://github.com/sorinirimies/stem-mqtt/releases):

- `bindings-zig.zip`: `bindings/zig/mqtt-client/` and `bindings/zig/mqtt-broker/`;
- `mqtt-client-<version>-<target>.tar.gz` and `mqtt-broker-<version>-<target>.tar.gz`: the libraries for
  your platform.

Put both components' `.zig` files next to each other (each imports `uniffi.zig` from its directory), then:

```sh
zig run app.zig -lc -L/path/to/libs -lmqtt_client -lmqtt_broker -rpath /path/to/libs
```

## Requirements

- Zig 0.17.

## Quick start

```zig
const std = @import("std");
const client = @import("mqtt_client.zig");

pub fn main() !void {
    const gpa = std.heap.c_allocator;
    const c = try client.MqttClient.init(.{
        .host = "127.0.0.1", .port = 1883, .client_id = "zig-client", .version = .v5,
        .clean_start = true, .keep_alive_secs = 30, .username = null, .password = null,
        .will = null, .connect_timeout_secs = 10, .operation_timeout_secs = 5,
        .auto_reconnect = false, .reconnect_backoff_secs = 0, .reconnect_max_backoff_secs = 0,
        .tls = null,
    });
    defer c.deinit();
    _ = try c.connect(gpa, null);
    try c.publish(gpa, "demo/zig", "hi", .at_least_once, false, null);
    try c.disconnect(gpa, null);
}
```

The complete example, a broker with an auth provider and an event listener and two clients, is the
runtime smoke test: [`tests/bindings/zig/smoke.zig`](../../tests/bindings/zig/smoke.zig).

## Notes

- **Errors** are Zig errors (`MqttError.Set`); pass a `*MqttError` to get the message.
- **Memory:** functions returning strings or records take an allocator; free what they return.
- **Async:** Rust's async methods block until done.
- **Callbacks:** any struct with the methods, wrapped with `MqttMessageListener.fromImpl(&impl)` (and
  likewise for the broker's traits). Rust calls them on its own threads.
