# Kotlin (JVM and Android)

Coroutine-based (`suspend`) bindings generated by UniFFI's built-in Kotlin backend, using
[JNA](https://github.com/java-native-access/jna) to reach the native library. One package contains the
client and the broker. Read the [shared concepts](README.md) first for the option records and semantics.

## Install

| Target | Coordinate | Registry |
| --- | --- | --- |
| JVM / desktop | `io.github.sorinirimies.stemmqtt:stem-mqtt-kotlin:<version>` | Maven Central |
| JVM / desktop | `com.github.sorinirimies.stemmqtt:stem-mqtt-kotlin:<version>` | GitHub Packages, Gitea Maven |
| Android | `com.github.sorinirimies.stemmqtt:stem-mqtt-android:<version>` | GitHub Packages |

```kotlin
// build.gradle.kts
dependencies {
    implementation("io.github.sorinirimies.stemmqtt:stem-mqtt-kotlin:<version>")   // JVM
    // implementation("com.github.sorinirimies.stemmqtt:stem-mqtt-android:<version>")  // Android
}
```

Maven Central needs no credentials. GitHub Packages requires a token with `read:packages` even for a
public repository:

```kotlin
// settings.gradle.kts
dependencyResolutionManagement {
    repositories {
        mavenCentral()
        maven {
            url = uri("https://maven.pkg.github.com/sorinirimies/stem-mqtt")
            credentials {
                username = providers.gradleProperty("gpr.user").getOrElse(System.getenv("GITHUB_ACTOR") ?: "")
                password = providers.gradleProperty("gpr.token").getOrElse(System.getenv("GITHUB_TOKEN") ?: "")
            }
        }
    }
}
```

The two groups differ only because Maven Central requires a verified `io.github.<user>` namespace.

## Requirements

- A recent JDK (CI uses 17) or Android API 24+; Kotlin with `kotlinx-coroutines-core` and JNA (both pulled in as dependencies).
- **JVM**: the jar embeds the native libraries for its publishing host — Linux x86_64 today. On other
  OSes build the package yourself (below). **Android**: the AAR carries all four ABIs
  (`arm64-v8a`, `armeabi-v7a`, `x86_64`, `x86`).

## Quick start

```kotlin
import kotlinx.coroutines.*
import uniffi.mqtt_broker.MqttBroker
import uniffi.mqtt_broker.MqttBrokerConfig
import uniffi.mqtt_client.*
import uniffi.mqtt_broker.QoS as BrokerQoS     // each component owns a QoS

fun options(port: UShort, id: String) = ConnectOptions(
    host = "127.0.0.1", port = port, clientId = id, version = MqttVersion.V5,
    cleanStart = true, keepAliveSecs = 30u, username = null, password = null, will = null,
    connectTimeoutSecs = 10u, operationTimeoutSecs = 5u, autoReconnect = false,
    reconnectBackoffSecs = 0u, reconnectMaxBackoffSecs = 0u, tls = null,
)

fun main() = runBlocking {
    val broker = MqttBroker(MqttBrokerConfig(
        bindAddress = "127.0.0.1", port = 0u, wsPort = null, allowAnonymous = true, maxClients = 0u,
        maxQos = BrokerQoS.EXACTLY_ONCE, maxRetainedMessages = 100u, maxQueuedPerClient = 100u,
        redeliveryIntervalSecs = 0u, tls = null,
    ))
    broker.start()
    val port = broker.boundPort()!!

    val received = CompletableDeferred<MqttMessage>()
    val sub = MqttClient(options(port, "kt-sub"))
    sub.setMessageListener(object : MqttMessageListener {
        override fun onMessage(message: MqttMessage) { received.complete(message) }
        override fun onDisconnected(reason: String) {}
    })
    sub.connect()
    sub.subscribe("demo/#", QoS.AT_LEAST_ONCE)

    val pub = MqttClient(options(port, "kt-pub"))
    pub.connect()
    pub.publish("demo/hello", "hello".toByteArray(), QoS.AT_LEAST_ONCE, false)

    val message = withTimeout(5_000) { received.await() }
    println("${message.topic}: ${String(message.payload)}")

    pub.disconnect(); sub.disconnect(); broker.stop()
}
```

`maxPacketSize`, `maxOutboundQueue`, `sessionExpirySecs`, `authMethod` and `authData` have defaults and
can be omitted.

## Client

- `connect()`, `subscribe(topicFilter, qos)`, `unsubscribe(topicFilter)`, `publish(topic, payload, qos, retain)`,
  `disconnect()` and `nextMessage(timeoutMs)` are **`suspend` functions**; `isConnected()`,
  `setMessageListener()`, `enableMessageQueue(capacity)`, `lastDisconnectReason()` are plain.
- Numbers are Kotlin **unsigned** types: ports are `UShort` (`1883u`), seconds `UInt` / `UShort`
  (`30u`). The literal suffix `u` is what you want.
- Enums are `UPPER_SNAKE`: `QoS.AT_MOST_ONCE | AT_LEAST_ONCE | EXACTLY_ONCE`, `MqttVersion.V311 | V5`.
  `payload` is `ByteArray`.
- **Callbacks** implement `MqttMessageListener` and run on a Rust thread — hand results to your
  coroutine scope (a `CompletableDeferred` or `Channel`, as above) instead of touching UI state directly.
- **Or pull**: `client.enableMessageQueue(16u)` then `client.nextMessage(5000u)` → `MqttMessage?`.
- Clients and brokers are `AutoCloseable`: `MqttBroker(config).use { … }` releases the native handle.

## Broker

`start()` / `stop()` are `suspend`; `isRunning()`, `boundPort(): UShort?`, `boundWsPort()`,
`boundTlsPort()`, `clientCount(): UInt`. Port `0u` picks a free port.

```kotlin
broker.setEventListener(object : MqttBrokerEventListener {
    override fun onClientConnected(clientId: String) = println("+ $clientId")
    override fun onClientDisconnected(clientId: String, reason: String) = println("- $clientId ($reason)")
    override fun onMessagePublished(clientId: String, topic: String, qos: BrokerQoS) {}
})
```

Pull-style: `broker.enableEventQueue(64u)`, `broker.nextEvent(1000u)` → `BrokerEvent?`.

## Authentication

```kotlin
broker.setAuthProvider(object : MqttAuthProvider {
    override fun authenticate(clientId: String, username: String?, password: ByteArray?) =
        username == "demo" && password?.decodeToString() == "demo"
})
```

A refused client makes `connect()` throw `MqttException.ConnectionRefused`. MQTT 5 enhanced
authentication: implement `MqttEnhancedAuthProvider.step(clientId, method, data, round)` returning
`EnhancedAuthStep(outcome = EnhancedAuthOutcome.CONTINUE | SUCCESS | FAILURE, data = …)` on the broker,
and `MqttAuthHandler.respond(method, challenge)` on the client (with `authMethod` / `authData` set).

## TLS

```kotlin
val tls = TlsOptions(
    caCertPem = File("ca.pem").readBytes(), clientCertPem = null, clientKeyPem = null,
    insecureSkipCertificateVerification = false,
)
// ConnectOptions(…, tls = tls)

val brokerTls = BrokerTlsConfig(port = 8883u, certPem = File("server.pem").readBytes(),
                                keyPem = File("server.key").readBytes(), clientCaPem = null)
// MqttBrokerConfig(…, tls = brokerTls)
```

## Language notes

- Errors are `uniffi.mqtt_client.MqttException` subclasses (`ConnectionRefused`, `Timeout`,
  `Protocol`, …) and `uniffi.mqtt_broker.MqttBrokerException` (`AlreadyRunning`, `Io`, `Tls`).
- Import both `QoS` types with an alias (the broker owns its own), as in the quick start.
- JNA needs the native library on its search path: the packaged jar handles this for its bundled
  platform; for a custom build set `-Djna.library.path=<dir>`.
- Android: add the AAR and use the same API; keep the broker off the main thread (it is a server).

## Building from source

```sh
just package-kotlin-jvm                  # stages generated Kotlin + native libs into packaging/kotlin/staged
cd packaging/kotlin && gradle build      # JVM jar; `gradle test` runs a start/stop smoke test

export ANDROID_NDK_HOME=… ANDROID_HOME=…
just package-kotlin-android              # all four ABIs
cd packaging/kotlin/android && gradle assembleRelease
```

Details: [`packaging/kotlin/README.md`](../../packaging/kotlin/README.md).

## Troubleshooting

- **`UnsatisfiedLinkError: Unable to load library 'mqtt_broker'`** — no native library for your
  OS/arch in the jar; build for your platform or set `jna.library.path`.
- **`401 Unauthorized` from GitHub Packages** — token missing `read:packages`; Maven Central has no such requirement.
- **`kotlin.UInt` type mismatch** — use unsigned literals (`30u`), not `30`.
- **Callbacks arrive on an unexpected thread** — expected; marshal to your dispatcher.
