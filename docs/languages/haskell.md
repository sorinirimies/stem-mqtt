# Haskell

Bindings generated by [`uniffi-bindgen-haskell`](https://github.com/mercury/uniffi-bindgen-haskell) (with
[our patch](../../packaging/haskell/README.md) for three upstream bugs), published on Hackage as `stem-mqtt`.
Calls are `IO` actions returning `Either` for fallible operations, and the API is **pull-style**: generated
Haskell cannot implement Rust callback interfaces. Read the [shared concepts](README.md) first for the option
records and semantics.

## Install

```sh
cabal install --lib stem-mqtt            # or add `stem-mqtt` to build-depends
```

```haskell
import UniFFI.MqttBroker
import qualified UniFFI.MqttClient as C
```

Import the client qualified: both modules define a `QoS`, and several record names overlap.

## Requirements

- GHC 9.2+ and `cabal` 3.4+ (the package uses `GHC2021`); tested with GHC 9.14.
- **A Rust toolchain (`cargo`)**. `stem-mqtt` is a source package that bundles the Rust sources; its custom
  `Setup.hs` runs `cargo build --release` at configure time and links the resulting static archive. The first
  build takes a minute or two.
- A C compiler (GHC already needs one) and `libc` / `libm` (`libdl`, `libpthread` on Linux).

## Quick start

```haskell
{-# LANGUAGE OverloadedStrings #-}
module Main (main) where

import qualified Data.ByteString.Char8 as B
import Data.Text (Text)
import Data.Word (Word16)

import UniFFI.MqttBroker
import qualified UniFFI.MqttClient as C

options :: Word16 -> Text -> C.ConnectOptions
options port clientId =
  C.ConnectOptions "127.0.0.1" port clientId C.MqttVersionV5 True 30 Nothing Nothing Nothing 10 5 False 0 0 Nothing 0 Nothing Nothing

main :: IO ()
main = do
  broker <- newMqttBroker (MqttBrokerConfig "127.0.0.1" 0 Nothing True 0 QoSExactlyOnce 100 100 0 Nothing 0 0 0)
  Right () <- mqttBrokerStart broker
  Just port <- mqttBrokerBoundPort broker

  sub <- C.newMqttClient (options port "hs-sub")
  C.mqttClientEnableMessageQueue sub 16               -- pull, don't push
  Right _ <- C.mqttClientConnect sub
  Right _ <- C.mqttClientSubscribe sub "demo/#" C.QoSAtLeastOnce

  pub <- C.newMqttClient (options port "hs-pub")
  Right _ <- C.mqttClientConnect pub
  Right () <- C.mqttClientPublish pub "demo/hello" (B.pack "hello") C.QoSAtLeastOnce False

  delivered <- C.mqttClientNextMessage sub 5000        -- Nothing on timeout
  case delivered of
    Just (C.MqttMessage topic payload _ _) -> print (topic, payload)
    Nothing -> putStrLn "no message"

  Right () <- C.mqttClientDisconnect pub
  Right () <- C.mqttClientDisconnect sub
  Right () <- mqttBrokerStop broker
  pure ()
```

`build-depends: base, bytestring, text, stem-mqtt`. Constructors are **positional**; the field order is the
Rust declaration order (see the tables in the [shared concepts](README.md); the last three
`ConnectOptions` fields — `maxPacketSize`, `authMethod`, `authData` — are `0`, `Nothing`, `Nothing`).

## Client

- Functions are named `mqttClient<Method>` and take the client first: `mqttClientConnect`,
  `mqttClientSubscribe client filter qos`, `mqttClientUnsubscribe`, `mqttClientPublish client topic payload qos retain`,
  `mqttClientDisconnect`, `mqttClientIsConnected`, `mqttClientEnableMessageQueue`, `mqttClientNextMessage client timeoutMs`.
- Fallible calls return `IO (Either MqttError a)`; `Text` for strings, strict `ByteString` for payloads,
  `Maybe` for optionals, `Word16` ports. Enums are constructors: `C.QoSAtLeastOnce`, `C.MqttVersionV5`.
- A small helper keeps call sites tidy:

```haskell
ok :: Show e => String -> Either e a -> IO a
ok what = either (\e -> fail (what ++ ": " ++ show e)) pure
```

- Results are records matched positionally: `C.ConnectResult sessionPresent reasonCode`,
  `C.SubscribeResult reasonCode`, `C.MqttMessage topic payload qos retain`.

## Broker

`newMqttBroker config`, `mqttBrokerStart`, `mqttBrokerStop` (both `IO (Either MqttBrokerError ())`),
`mqttBrokerIsRunning`, `mqttBrokerBoundPort :: IO (Maybe Word16)`, `mqttBrokerClientCount`,
`mqttBrokerEnableEventQueue broker capacity`, `mqttBrokerNextEvent broker timeoutMs`.

```haskell
mqttBrokerEnableEventQueue broker 16                         -- before start
let drain acc = mqttBrokerNextEvent broker 300 >>= maybe (pure acc) (\e -> drain (e : acc))
events <- drain []
print [c | BrokerEventClientConnected c <- events]
```

Events are `BrokerEventClientConnected clientId`, `BrokerEventClientDisconnected clientId reason`,
`BrokerEventMessagePublished clientId topic qos`.

## Authentication

Custom `MqttAuthProvider` / enhanced-authentication callbacks can't be written in Haskell. Use the broker's
built-in rule instead: with `allowAnonymous = False` a client that sends **no username** is refused, and a
client that sends one is accepted (there is no password check without a provider callback — run the broker
from another language if you need one). A refused client's `mqttClientConnect` returns `Left …`.

```haskell
refused <- C.mqttClientConnect =<< C.newMqttClient (options port "anon")   -- Left … when allowAnonymous is False
```

## TLS

```haskell
ca <- B.readFile "ca.pem"
let tls = C.TlsOptions (Just ca) Nothing Nothing False       -- caCertPem, clientCertPem, clientKeyPem, insecureSkip…
-- put `Just tls` in the `tls` slot of C.ConnectOptions

cert <- B.readFile "server.pem"; key <- B.readFile "server.key"
let brokerTls = BrokerTlsConfig 8883 cert key Nothing        -- port, certPem, keyPem, clientCaPem
-- put `Just brokerTls` in the `tls` slot of MqttBrokerConfig
```

## Language notes

- Errors are values (`Either`), never exceptions; `Show` them for the message.
- Operations block the calling thread; use `forkIO` / `async` for concurrency. Compile with `-threaded`
  (the smoke test does) so a blocked call doesn't stall other Haskell threads.
- The generated modules carry `UniFFI.Runtime` (Apache-2.0, from upstream) — see `LICENSE.uniffi-runtime`.

## Building from source

```sh
nu scripts/install_bindgens.nu haskell
nu scripts/publish_packages.nu stage haskell        # dist/haskell/hackage is the source package
cd dist/haskell/hackage && cabal build && cabal sdist && cabal check
```

The end-to-end test builds this very package and runs [`tests/bindings/haskell/Main.hs`](../../tests/bindings/haskell/Main.hs).

## Troubleshooting

- **`stem-mqtt: cargo build failed — is a Rust toolchain installed?`** — install Rust (<https://rustup.rs>);
  the build output follows the message.
- **`Ambiguous occurrence 'QoS'`** — import `UniFFI.MqttClient` qualified.
- **Linker errors mentioning `uniffi_mqtt_…`** — the Rust archive wasn't built or is stale: delete
  `rust/target` in the unpacked package and rebuild.
- **`-Wname-shadowing` warnings** in generated code — harmless; the package does not enable `-Wall`.
