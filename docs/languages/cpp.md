# C++

C++17 bindings generated by [`uniffi-bindgen-cpp`](https://github.com/sorinirimies/uniffi-bindgen-cpp): a
header and a source file per component (namespaces `mqtt_client`, `mqtt_broker`) plus the header-only
`uniffi_runtime.hpp`, compiled into your program and linked to the native libraries. Read the
[shared concepts](README.md) first for the option records and semantics.

## Install

From the [release](https://github.com/sorinirimies/stem-mqtt/releases):

- `bindings-cpp.zip`: `bindings/cpp/mqtt-client/` and `bindings/cpp/mqtt-broker/` (`.hpp`, `.cpp`,
  `uniffi_runtime.hpp`);
- `mqtt-client-<version>-<target>.tar.gz` and `mqtt-broker-<version>-<target>.tar.gz`: the libraries for
  your platform.

```sh
c++ -std=c++17 -pthread -Ibindings/cpp/mqtt-client -Ibindings/cpp/mqtt-broker \
    app.cpp bindings/cpp/mqtt-client/mqtt_client.cpp bindings/cpp/mqtt-broker/mqtt_broker.cpp \
    -L/path/to/libs -lmqtt_client -lmqtt_broker -Wl,-rpath,/path/to/libs -o app
```

## Requirements

- A C++17 compiler.

## Quick start

```cpp
#include "mqtt_client.hpp"

mqtt_client::ConnectOptions o;
o.host = "127.0.0.1";
o.port = 1883;
o.client_id = "cpp-client";
o.version = mqtt_client::MqttVersion::V5;
o.keep_alive_secs = 30;
o.connect_timeout_secs = 10;
o.operation_timeout_secs = 5;
auto client = mqtt_client::MqttClient::new_(o);
client->connect().get();
client->publish("demo/cpp", {'h', 'i'}, mqtt_client::QoS::AtLeastOnce, false).get();
client->disconnect().get();
```

The complete example, a broker with an auth provider and an event listener and two clients, is the
runtime smoke test: [`tests/bindings/cpp/smoke.cpp`](../../tests/bindings/cpp/smoke.cpp).

## Notes

- **Async:** Rust's async methods return `uniffi::Future<T>`; `.get()` blocks, `.then(...)` continues.
- **Errors** are exceptions derived from `mqtt_client::MqttError` / `mqtt_broker::MqttBrokerError`
  (one class per variant). Without exceptions, generate with `--no-exceptions`: calls return
  `uniffi::Result<T, std::shared_ptr<E>>` instead.
- **Callbacks:** subclass `mqtt_client::MqttMessageListener` (or the broker's traits) and pass a
  `std::shared_ptr`; Rust calls it on its own threads.
- Records and enums have `==`, `std::hash` and, with C++20 `<format>`, `std::formatter` where Rust has
  `Display`.
