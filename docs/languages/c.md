# C

C11 bindings generated by [`uniffi-bindgen-c`](https://github.com/sorinirimies/uniffi-bindgen-c): a header
and a source file per component (`mqtt_client`, `mqtt_broker`) plus the header-only `uniffi_runtime.h`,
compiled into your program and linked to the native libraries. Read the [shared concepts](README.md)
first for the option records and semantics.

## Install

From the [release](https://github.com/sorinirimies/stem-mqtt/releases):

- `bindings-c.zip`: `bindings/c/mqtt-client/` and `bindings/c/mqtt-broker/` (`.h`, `.c`, `uniffi_runtime.h`);
- `mqtt-client-<version>-<target>.tar.gz` and `mqtt-broker-<version>-<target>.tar.gz`: the libraries
  (`libmqtt_client.{a,so,dylib}`, ...) for your platform.

```sh
cc -std=c11 -pthread -Ibindings/c/mqtt-client -Ibindings/c/mqtt-broker \
   app.c bindings/c/mqtt-client/mqtt_client.c bindings/c/mqtt-broker/mqtt_broker.c \
   -L/path/to/libs -lmqtt_client -lmqtt_broker -Wl,-rpath,/path/to/libs -o app
```

## Requirements

- A C11 compiler (GCC, Clang); POSIX threads for callbacks arriving on Rust's threads.

## Quick start

```c
#include "mqtt_broker.h"
#include "mqtt_client.h"

uniffi_status st = {0};
mqtt_client_ConnectOptions o = mqtt_client_ConnectOptions_DEFAULTS;
o.host = uniffi_str("127.0.0.1");
o.port = 1883;
o.client_id = uniffi_str("c-client");
o.version = mqtt_client_MqttVersion_V5;
o.keep_alive_secs = 30;
o.connect_timeout_secs = 10;
o.operation_timeout_secs = 5;
mqtt_client_MqttClient client = mqtt_client_MqttClient_new(o, &st);
mqtt_client_MqttError err = {0};
mqtt_client_MqttClient_connect(client, &err, &st);
mqtt_client_MqttClient_publish(client, uniffi_str("demo/c"), uniffi_bytes_view("hi", 2),
                               mqtt_client_QoS_AtLeastOnce, false, &err, &st);
if (st.code != 0) { /* err.tag, err.message */ mqtt_client_MqttError_free(&err); uniffi_status_free(&st); }
mqtt_client_MqttClient_free(client);
```

The complete example, a broker with an auth provider and an event listener and two clients, is the
runtime smoke test: [`tests/bindings/c/smoke.c`](../../tests/bindings/c/smoke.c).

## Notes

- **Ownership:** arguments are borrowed; returned values are the caller's, freed with the matching
  `*_free` (`uniffi_string_free`, `mqtt_client_MqttMessage_free`, ...). Objects are handles freed with
  `mqtt_client_MqttClient_free`.
- **Errors:** every call takes a trailing `uniffi_status *` (NULL aborts on any error). Calls that can fail
  with an `MqttError` take an `mqtt_client_MqttError *` too, filled when `status->code` says so.
- **Async:** Rust's async methods block in the plain function; `<name>_async` takes a completion callback.
- **Callbacks** (`MqttMessageListener`, `MqttAuthProvider`, `MqttBrokerEventListener`, ...): a static
  vtable and a context pointer, wrapped with `<Type>_from_impl(&vtable, ctx)`. Rust calls them on its own
  threads: guard shared state.
