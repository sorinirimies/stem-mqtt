# Lua

Lua C modules generated by [`uniffi-bindgen-lua`](https://github.com/sorinirimies/uniffi-bindgen-lua), for
Lua 5.1 to 5.5 and LuaJIT: one C source per component (`mqtt_client`, `mqtt_broker`), each built into a
module (`mqtt_client.so`) linked to its native library. Read the [shared concepts](README.md) first for
the option records and semantics.

## Install

From the [release](https://github.com/sorinirimies/stem-mqtt/releases):

- `bindings-lua.zip`: `bindings/lua/mqtt-client/` and `bindings/lua/mqtt-broker/` (`.c`, `uniffi_lua.h`,
  `uniffi_runtime.h`);
- `mqtt-client-<version>-<target>.tar.gz` and `mqtt-broker-<version>-<target>.tar.gz`: the libraries for
  your platform.

Build each module against your Lua's headers (macOS: `-undefined dynamic_lookup` instead of `-fPIC`):

```sh
cc -std=c11 -shared -fPIC -pthread -Ibindings/lua/mqtt-client -I/usr/include/lua5.4 \
   bindings/lua/mqtt-client/mqtt_client.c -L/path/to/libs -lmqtt_client -Wl,-rpath,/path/to/libs \
   -o mqtt_client.so
```

## Requirements

- Lua with its headers (the generator supports 5.1–5.5 and LuaJIT; the smoke test runs on 5.4 in CI and
  5.5), and a C11 compiler.

## Quick start

```lua
local mqtt_client = require("mqtt_client")

local client = mqtt_client.MqttClient.new({
    host = "127.0.0.1", port = 1883, client_id = "lua-client", version = "V5",
    clean_start = true, keep_alive_secs = 30, connect_timeout_secs = 10, operation_timeout_secs = 5,
    auto_reconnect = false, reconnect_backoff_secs = 0, reconnect_max_backoff_secs = 0,
})
client:set_message_listener(mqtt_client.MqttMessageListener.from_impl({
    on_message = function(_, m) print(m.topic, m.payload) end,
    on_disconnected = function() end,
}))
client:connect()
client:subscribe("demo/#", "AtLeastOnce")
client:publish("demo/lua", "hi", "AtLeastOnce", false)
-- in your event loop: mqtt_client.poll() runs the callbacks
```

The complete example, a broker with an auth provider and an event listener and two clients, is the
runtime smoke test: [`tests/bindings/lua/smoke.lua`](../../tests/bindings/lua/smoke.lua).

## Notes

- **Threads:** Rust calls callbacks on its own threads; they run on the Lua thread during any call into
  either module (async calls wait there) or in `poll()`. A callback returning a value (the broker's
  `authenticate`) blocks the Rust thread until then, so call `poll()` regularly in an event loop.
- **Values:** records are tables, enums their variant name (`"AtLeastOnce"`), `Option` is `nil`, bytes are
  strings. Errors are raised as tables: `err.tag` (`"ConnectionRefused"`, ...) and `err.message`.
- **Callbacks** are traits: wrap a table of methods with `Type.from_impl(table)`.
