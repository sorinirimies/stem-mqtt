# Go

A cgo module generated by [`uniffi-bindgen-go`](https://github.com/NordSecurity/uniffi-bindgen-go). Calls are
**blocking** (run them in goroutines); callbacks are Go interfaces. Two packages, `mqtt_client` and
`mqtt_broker`. Read the [shared concepts](README.md) first for the option records and semantics.

## Install

```sh
go get github.com/sorinirimies/stem-mqtt-go@latest
```

```go
import (
    "github.com/sorinirimies/stem-mqtt-go/mqtt_broker"
    "github.com/sorinirimies/stem-mqtt-go/mqtt_client"
)
```

The module repository is generated and tagged by the release workflow
(`scripts/publish_go_module.nu`); file issues on the main repository.

## Requirements

- Go 1.21+ and **cgo** (`CGO_ENABLED=1`, a C compiler).
- The native libraries **`libmqtt_client` and `libmqtt_broker` are not in the module** — install them
  (release assets, or `cargo build --release -p stem-mqtt-client -p stem-mqtt-broker`) and point cgo
  and the loader at them:

```sh
export CGO_LDFLAGS="-L/path/to/libs"
export LD_LIBRARY_PATH=/path/to/libs        # macOS: DYLD_LIBRARY_PATH, Windows: PATH
go build ./...
```

  The module already sets `#cgo CFLAGS: -I${SRCDIR}` (headers ship with it) and
  `#cgo LDFLAGS: -lmqtt_client` / `-lmqtt_broker`.

## Quick start

```go
package main

import (
	"fmt"
	"time"

	"github.com/sorinirimies/stem-mqtt-go/mqtt_broker"
	"github.com/sorinirimies/stem-mqtt-go/mqtt_client"
)

type inbox struct{ ch chan mqtt_client.MqttMessage }

func (i *inbox) OnMessage(m mqtt_client.MqttMessage) { i.ch <- m }
func (i *inbox) OnDisconnected(reason string)         {}

func options(port uint16, id string) mqtt_client.ConnectOptions {
	return mqtt_client.ConnectOptions{
		Host: "127.0.0.1", Port: port, ClientId: id, Version: mqtt_client.MqttVersionV5,
		CleanStart: true, KeepAliveSecs: 30, ConnectTimeoutSecs: 10, OperationTimeoutSecs: 5,
	}
}

func main() {
	broker := mqtt_broker.NewMqttBroker(mqtt_broker.MqttBrokerConfig{
		BindAddress: "127.0.0.1", Port: 0, AllowAnonymous: true,
		MaxQos: mqtt_broker.QoSExactlyOnce, MaxRetainedMessages: 100, MaxQueuedPerClient: 100,
	})
	if err := broker.Start(); err != nil {
		panic(err)
	}
	port := *broker.BoundPort()

	in := &inbox{ch: make(chan mqtt_client.MqttMessage, 4)}
	sub := mqtt_client.NewMqttClient(options(port, "go-sub"))
	sub.SetMessageListener(in)
	if _, err := sub.Connect(); err != nil {
		panic(err)
	}
	if _, err := sub.Subscribe("demo/#", mqtt_client.QoSAtLeastOnce); err != nil {
		panic(err)
	}

	pub := mqtt_client.NewMqttClient(options(port, "go-pub"))
	if _, err := pub.Connect(); err != nil {
		panic(err)
	}
	if err := pub.Publish("demo/hello", []byte("hello"), mqtt_client.QoSAtLeastOnce, false); err != nil {
		panic(err)
	}

	select {
	case m := <-in.ch:
		fmt.Printf("%s: %s\n", m.Topic, m.Payload)
	case <-time.After(5 * time.Second):
		fmt.Println("timed out")
	}

	pub.Disconnect()
	sub.Disconnect()
	broker.Stop()
}
```

Fields you leave out keep Go's zero value, which is the "default" for every optional/limit field
(`0` = built-in default, `nil` = none) — hence no `MaxPacketSize`, `Tls` or `Will` above.

## Client

- `Connect() (ConnectResult, error)`, `Subscribe(filter, qos) (SubscribeResult, error)`,
  `Unsubscribe(filter) error`, `Publish(topic, []byte, qos, retain) error`, `Disconnect() error`.
  All block until the broker answers (QoS handshakes included). `IsConnected()`, `SetMessageListener()`,
  `EnableMessageQueue(capacity)`, `LastDisconnectReason() *string` don't block.
- Names are PascalCase; optional values are pointers (`Username *string`, `Password *[]byte`,
  `Will *WillOptions`, `Tls *TlsOptions`). Enums are typed constants: `mqtt_client.QoSAtLeastOnce`,
  `mqtt_client.MqttVersionV5`.
- **Callbacks** implement `MqttMessageListener` (`OnMessage`, `OnDisconnected`) and are invoked from a
  native thread — push into a channel as above, don't block in them.
- **Or pull**: `EnableMessageQueue(16)`, then `sub.NextMessage(5000)` returns a `*MqttMessage`, `nil`
  on timeout.
- Pass optionals by pointer: `user := "demo"; opts.Username = &user`.

## Broker

`NewMqttBroker(config) *MqttBroker`; `Start() error`, `Stop() error`, `IsRunning() bool`,
`BoundPort() *uint16`, `BoundWsPort()`, `BoundTlsPort()`, `ClientCount() uint32`.

```go
type events struct{}
func (events) OnClientConnected(id string)                                {}
func (events) OnClientDisconnected(id, reason string)                     {}
func (events) OnMessagePublished(id, topic string, qos mqtt_broker.QoS)   {}

broker.SetEventListener(events{})
```

Pull-style: `EnableEventQueue(64)`, `NextEvent(1000)` returns a `BrokerEvent` (a type switch over
`BrokerEventClientConnected`, `…ClientDisconnected`, `…MessagePublished`) or `nil`.

## Authentication

```go
type auth struct{}
func (auth) Authenticate(clientId string, username *string, password *[]byte) bool {
	return username != nil && *username == "demo"
}
broker.SetAuthProvider(auth{})
```

A refused client makes `Connect()` return an error: test with
`errors.Is(err, mqtt_client.ErrMqttErrorConnectionRefused)`. Enhanced authentication: implement
`MqttEnhancedAuthProvider.Step(clientId, method string, data *[]byte, round uint32) EnhancedAuthStep`
(broker) and `MqttAuthHandler.Respond(method string, challenge []byte) []byte` (client, with
`AuthMethod` / `AuthData` set).

## Language notes

- **Errors** are values: `errors.Is(err, mqtt_client.ErrMqttErrorTimeout)` and friends
  (`ErrMqttError<Variant>`); the broker has `mqtt_broker.ErrMqttBrokerError<Variant>`.
- **Every call blocks the goroutine**, so run client and broker work in goroutines; there is no
  `context` support — use `operation_timeout_secs` / `connect_timeout_secs`.
- The generated objects own native handles; they are released by a finalizer, or explicitly with
  `Destroy()` when you want deterministic cleanup.
- Alias or qualify the two `QoS` types; they are distinct Go types.

## Troubleshooting

- **`ld: library 'mqtt_client' not found`** — set `CGO_LDFLAGS=-L<dir>` to where the libraries live.
- **`error while loading shared libraries: libmqtt_client.so`** at run time — add the directory to
  `LD_LIBRARY_PATH` (`DYLD_LIBRARY_PATH` on macOS).
- **`cgo: C compiler "gcc" not found`** — install a C toolchain; cgo cannot be disabled for this module.
- **A deadlock in a callback** — callbacks run on a native thread; don't call back into the same client
  and wait for it from inside `OnMessage`.
